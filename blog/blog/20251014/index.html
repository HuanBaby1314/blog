教师编制

  • 公告查询途径
    1. 全国事业单位招聘网官网全国事业单位公告都在这儿，招考信息、报名信息、录用信息等信息很全的网站
    2. 各省市人事考试或教育局官网这里可以看到全省统一发布的招聘考试信息
    3. 各省人力资源与社会保障局当地统一的事业单位招聘信息、就业信息、人事考试技能鉴定都有
    4. 教考、机构的官网/gzh教育机构会整合所有的相关招考、报名等信息
    5. 小红书、b站等社交平台
  • 获取教编的方式及考试时间
    1. 教招（统考）：3-4月报名，5-7月考试，只要考上就有编制
    2. 事业编D类（联考）：3-5月报名，8-10月考试，蕞正经的编制
    3. 特岗教师：4-7月报名，8月考试，有3年的服务期，期满以后转编
    4. 校招：春招3-6月，秋招9-12月，考试时间以具体公告为准⚠注意！！部分校招是没有编制的！！虽然现在官方对外的告示是非编的待遇同编制一样，但目的是想要编制的同学一定要看清楚！！
  • 报考条件
    1. 教招（统考）：专业一致、相应的教资证、普通话、35周岁以下
    2. 事业编D类（联考）：本科及以上、专业一致、相应的教资证、普通话、35周岁以下
    3. 特岗教师：本科及以上、相应的教资证、30周岁以下
    4. 校招：一般只招应届⚠各地各岗都可能会有特殊的要求，比如应届或户籍，研究生以上年龄放宽等，要看具体的公告信息！！
  • 考试内容
    1. 教招（统考）：教基/教基+职测/教基+公基
    2. 事业编D类（联考）：职测+综应
    3. 特岗教师：教综/教综+学科/教综+公基
    4. 校招：一般只有面试，部分会有笔试面试类型：试讲/说课/结构化
  • 备考资料怎么选
    1. 教材：粉笔、华图、中公
    2. 网课：马克、李铁、花生十三
    3. 工具：公考雷达、半月谈、粉笔职教
